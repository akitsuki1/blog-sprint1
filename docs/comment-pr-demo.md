# Comment Function - Issue #4

Developer: Ruby
Story Points: 1
Sprint: Sprint 1

## Requirements
- Allow logged-in users to add comments
- Enter comment content
- Validate comment content
- Link comments to existing blog posts
- Display comments below blog posts

## Acceptance Criteria
- Valid comments are saved
- Empty comments are rejected
- Comments appear on the correct post
- Unauthenticated users cannot add comments
