# Post Function - Issue #3

Developer: David
Story Points: 3
Sprint: Sprint 1

## Requirements
- Allow authenticated users to create posts
- Enter post title and content
- Validate required fields
- Store posts in the database
- Display published posts
- Record author and publication time

## Acceptance Criteria
- Valid posts are created
- Empty title is rejected
- Post content is saved correctly
- Published posts are displayed
- Unauthenticated users cannot create posts
